# LNU-LibSeat v2.5.2

**PySide6 图形界面 · API 候选选择 · 单账号续约计划倒计时 · 多账号多方案 · 启动恢复提示**

v2.5.2 继续强化“预约筛选助手”的定位：先扫描、再让用户选择，最后才执行真实预约。这个版本重点优化长时间学习场景、跨房间选择和多账号分段选择。

> 第一次使用请先开启测试模式。测试模式会弹出候选/方案选择窗口，但不会预约、取消或换座。

## 主要更新

| 更新 | 说明 |
| --- | --- |
| 单账号续约计划 | 第一段真实预约成功后，右侧显示当前预约、目标覆盖、下一次扫描时间、倒计时和后续预案。 |
| 单账号候选选择 | 首次预约和下一段换座都可选择当前房间、全局最佳和勾选房间最佳候选。 |
| 多账号多方案 | 多账号模式生成最多 3 套完整方案，用户选择一套后才执行。 |
| 少账号优先 | 如果账号 1 一个座位能覆盖目标时长，也会作为合法方案展示。 |
| 测试模式预览 | 测试模式下也弹出候选/方案选择，并显示单账号续约预览。 |
| 启动恢复提示 | 单账号真实运行中误关闭后，下次打开软件会展示关闭前续约计划，可选择继续或不管。 |

## 推荐使用流程

1. 填写账号、校区、房间和目标时段。
2. 先开启测试模式。
3. 单账号模式下查看候选弹窗和右侧续约预览。
4. 多账号模式下查看最多 3 套完整方案。
5. 确认方案合理后关闭测试模式，再执行真实预约。

## 单账号逐段注意事项

- 真实预约成功后才会保存可恢复计划。
- 测试模式的续约预览不会在重启后恢复。
- 右侧“续约计划”里的后续预案只是当前扫描结果的参考，倒计时结束后仍会重新扫描确认。
- 未开启自动取消时，找到下一段后会弹窗让你选择候选。
- 开启自动取消后，程序会按推荐候选直接取消当前预约并预约下一段，第一次使用不建议开启。

## 多账号注意事项

- 多账号按“整套方案”选择，不支持只替换某一段。
- 方案可能只使用账号 1，也可能使用 2-3 个账号。
- 如果只想待在当前房间，可优先选择当前房间方案。
- 如果更看重连续覆盖时间，可选择最长覆盖或其他房间方案。

## 关闭和恢复

单账号真实运行中关闭程序时，会保存当前预约、下一次扫描时间和后续预案。下次打开软件时：

1. 程序先弹窗展示关闭前续约计划。
2. 选择“继续计划”后，会按保存配置启动单账号真实模式。
3. 登录后会查询服务器“我的预约”。
4. 若服务器仍有有效预约，再选择继续上次计划、重新扫描或停止。
5. 选择“不管”只清理本地恢复提示，不会取消服务器上的预约。
