# screenshots

这里用于存放真实界面截图。当前文档不强制依赖截图。

建议截图：

| 文件名 | 内容 |
| --- | --- |
| `01_main_window.png` | 主界面整体。 |
| `02_single_mode.png` | 单账号逐段设置区域。 |
| `03_multi_mode.png` | 多账号分时段设置。 |
| `04_help_dialog.png` | 首次帮助窗口。 |
| `05_resume_dialog.png` | 重启恢复选择弹窗。 |
| `06_api_plan_log.png` | API 方案日志输出。 |

如果你手动上传截图，建议使用上述命名，后续可以把图片链接补进 `QUICKSTART.md` 和 `USER_GUIDE.md`。
