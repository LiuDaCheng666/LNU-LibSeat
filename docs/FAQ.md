# 常见问题

[返回文档中心](README.md)

## 第一次运行应该先做什么

先开启测试模式，确认 API 能扫描出方案。测试模式不会预约、取消或换座。

## 为什么不上传 env 到 GitHub

`env/` 是本地虚拟环境，体积大且不可移植。上传 `requirements.txt` 即可，别人运行 `run.bat` 会自动重建环境。

## 单账号模式关闭程序后会取消预约吗

通常不会。关闭程序会停止本地计时和自动换座，但服务器上已经预约成功的当前座位仍然存在。下次启动后程序会查询“我的预约”，再询问是否恢复。

## 恢复时为什么还要登录查询

本地保存的信息可能过期。服务器“我的预约”才是当前真实状态，所以恢复前必须查询。

## 自动取消并换座安全吗

它适合确认流程稳定后使用。第一次建议关闭该选项，让程序找到下一段后弹窗确认。

## 找到下一段后，新座位预约失败怎么办

程序会在日志中记录失败阶段。如果失败发生在当前预约已经取消后，恢复状态会保留敏感阶段，重启后仍会先查询服务器当前预约。

## 主题切换为什么要重启

当前 UI 主题样式在启动时生成。切换主题会保存偏好，重启后完整应用新主题。

## GitHub 上传前要清理什么

确认 `config_data.json` 没有真实账号密码，不上传 `single_runtime_state.json`、`logs/`、`env/`、`build/`、`dist/`。
