# 快速开始

[返回文档中心](README.md)

## 运行环境

| 要求 | 说明 |
| --- | --- |
| 系统 | Windows 10 / 11 优先。 |
| 浏览器 | Microsoft Edge。 |
| 网络 | 能访问辽宁大学图书馆座位预约系统。 |
| Python | 源码运行需要 Python；打包版用户不需要自己配置 Python。 |

## 方式一：运行打包版

1. 解压 `dist/LNU-LibSeat-v2.5.2.zip`。
2. 双击 `LNU-LibSeat.exe`。
3. 首次启动会弹出使用帮助，阅读后点击“我知道了”。
4. 填写账号、校区、房间、目标时间段。
5. 建议第一次勾选“测试模式”，点击开始，确认 API 能扫描出候选或多账号方案。
6. 取消“测试模式”后，再执行真实预约。

## 方式二：源码运行

在项目根目录执行：

```powershell
.\run.bat
```

`run.bat` 会创建 `env` 虚拟环境、安装依赖，并用 `pythonw.exe app.py` 启动 GUI。

已安装依赖时，也可以手动运行：

```powershell
env\Scripts\python.exe app.py
```

## 第一次应该怎么配置

| 区域 | 建议 |
| --- | --- |
| 账号 | 先填写第一个账号。单账号模式只使用第一个账号。 |
| 校区/房间 | 选择真实想预约的目标房间。 |
| 时间段 | 例如 `09:00-21:00`。程序会按当前时间和学校开放时间自动校正。 |
| 跨房间 | 新手可以先开启，并勾选愿意接受的房间。 |
| 优先座位 | 可不填；若填写，配合“优先座位优先”使用。 |
| 测试模式 | 第一次建议开启，不会执行真实预约。 |
| 单账号提前提醒 | 例如 `30` 分钟，表示当前预约结束前 30 分钟扫描下一段。 |
| 自动取消并换座 | 第一次不建议开启，先使用弹窗确认。 |

## 一个单账号逐段例子

目标：从 `09:00` 学到 `21:00`。

1. 选择“单账号逐段”。
2. 设置时间段 `09:00-21:00`。
3. 设置提前 `30` 分钟查找下一座位。
4. 程序先预约第一段，例如 `09:00-14:00`。
5. 第一段成功后，右侧“续约计划”显示下一次扫描时间和倒计时。
6. 到 `13:30` 时开始扫描 `14:00` 后的下一段。
7. 找到下一段后弹窗展示可选候选。
8. 选择候选后，程序取消当前预约并预约新座位。

## 一个多账号多方案例子

目标：用最多 3 个账号覆盖 `09:00-15:00`。

程序可能给出：

| 方案 | 内容 |
| --- | --- |
| 方案 1 | 账号 1，A 房间 23 号，`09:00-15:00`。 |
| 方案 2 | 账号 1，A 房间 73 号，`09:00-11:00`；账号 2，A 房间 100 号，`11:00-15:00`。 |
| 方案 3 | 账号 1，B 房间 89 号，`09:00-12:00`；账号 2，B 房间 90 号，`12:00-15:00`。 |

选择一套后才会执行真实预约。测试模式只显示和记录选择。

## 注意

- 测试模式不会预约、取消或换座。
- 测试模式下的单账号续约预览不会保存为可恢复任务。
- 真实模式会提交预约和取消操作。
- 运行中尽量不要手动操作自动打开的浏览器。
- 关闭运行中的程序会停止本次计时，但单账号真实模式会保存恢复状态，下次打开软件会提示是否继续关闭前计划。
