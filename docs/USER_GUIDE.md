# 用户使用指南

[返回文档中心](README.md)

## 普通预约

普通预约适合只需要预约一段较短时间，例如 `09:00-12:00`。

操作步骤：

1. 填写第一个账号。
2. 选择校区和目标房间。
3. 设置目标时间段。
4. 可选：填写优先座位。
5. 点击开始。
6. 程序通过 API 扫描座位，弹窗展示推荐方案。
7. 确认后自动打开浏览器并完成预约。

## 单账号逐段预约

单账号逐段适合目标时间很长，但系统单次预约时长有限，或没有一个座位能覆盖完整时间段。

关键设置：

| 设置 | 含义 |
| --- | --- |
| 提前 N 分钟 | 当前预约结束前 N 分钟开始查找下一段。 |
| 自动取消并换座 | 找到下一段后跳过确认，直接取消当前预约并预约新座位。 |
| 跨房间 | 当前房间无合适方案时，扫描其他勾选房间。 |

推荐新手流程：

1. 开启单账号逐段。
2. 不勾选自动取消并换座。
3. 设置提前 `30` 分钟。
4. 第一次使用先跑测试模式。
5. 确认方案合理后再真实运行。

## 多账号分时段

多账号分时段适合多个账号覆盖较长时间。

例子：

| 账号 | 预约段 |
| --- | --- |
| 账号 1 | `09:00-13:00` |
| 账号 2 | `13:00-17:00` |
| 账号 3 | `17:00-21:00` |

程序会先生成分段方案，用户确认后依次登录账号并执行预约。若中间某一段失败，日志会显示失败原因。

## 跨房间搜索

开启跨房间后，程序会先看目标房间，再扫描你勾选的其他房间。

建议：

- 只勾选自己愿意去的房间。
- 如果只想坐固定房间，就关闭跨房间。
- 跨房间候选明显更长时，程序会优先推荐更合适的方案。

## 优先座位

优先座位用于表达“我更想坐这些座位”。

| 策略 | 说明 |
| --- | --- |
| 最长时段优先 | 先选可用时间最长的座位。 |
| 优先座位优先 | 优先考虑填写的座位；不可用时回退到最长时段。 |

## 首次帮助和主题切换

- 首次打开程序会自动弹出帮助窗口。
- 标题栏 `?` 按钮可以随时重新打开帮助。
- 月亮/太阳按钮可以切换亮色/暗色主题。
- 主题切换需要重启应用才能完全生效。

## 关闭和恢复

单账号逐段运行时，如果关闭程序：

1. 程序会先保存当前运行状态。
2. 弹窗询问是否确认退出。
3. 下次启动单账号模式时，程序会登录并查询“我的预约”。
4. 若查到有效预约，会询问继续上次计划、重新扫描或停止。
