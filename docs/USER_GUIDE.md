# 用户使用指南

[返回文档中心](README.md)

## 普通预约

普通预约适合只需要预约一段较短时间，例如 `09:00-12:00`。

操作步骤：

1. 填写第一个账号。
2. 选择校区和目标房间。
3. 设置目标时间段。
4. 可选：填写优先座位。
5. 点击开始。
6. 程序通过 API 扫描座位，弹窗展示可选候选。
7. 选择候选后自动打开浏览器并完成预约。

## 单账号逐段预约

单账号逐段适合目标时间很长，但系统单次预约时长有限，或没有一个座位能覆盖完整时间段。

关键设置：

| 设置 | 含义 |
| --- | --- |
| 提前 N 分钟 | 当前预约结束前 N 分钟开始查找下一段。 |
| 自动取消并换座 | 找到下一段后跳过确认，直接取消当前预约并预约新座位。 |
| 跨房间 | 当前房间无合适方案时，扫描其他勾选房间。 |

推荐新手流程：

1. 开启单账号逐段。
2. 不勾选自动取消并换座。
3. 设置提前 `30` 分钟。
4. 第一次使用先跑测试模式。
5. 在测试模式弹窗里选择候选，右侧会显示续约预览。
6. 确认方案合理后再真实运行。

真实运行时，第一段预约成功后，右侧日志上方会出现“续约计划”状态区，显示当前预约、目标覆盖、下一次扫描时间和倒计时。后续预案只是根据当前扫描结果推算出来的参考，倒计时结束后仍会重新扫描确认。

## 多账号分时段

多账号分时段适合多个账号覆盖较长时间。

例子：

| 账号 | 预约段 |
| --- | --- |
| 账号 1 | `09:00-13:00` |
| 账号 2 | `13:00-17:00` |
| 账号 3 | `17:00-21:00` |

程序会先生成最多 3 套完整分段方案，用户选择一套后依次登录账号并执行预约。账号不是必须用满：如果账号 1 的一个座位就能覆盖目标时长，它也会作为一套合法方案展示。

常见方案类型：

- 少账号优先方案：优先用账号 1 完成目标时长。
- 当前房间分段/优先方案：尽量留在目标房间。
- 最长覆盖方案或其他房间方案：在勾选范围内追求更长覆盖。

若中间某一段失败，日志会显示失败原因。

## 跨房间搜索

跨房间默认关闭。开启后，程序会先看目标房间，再扫描你勾选的其他房间。

建议：

- 只勾选自己愿意去的房间。
- 勾选房间越多，API 请求越多，等待时间越久。
- 如果只想坐固定房间，就关闭跨房间。
- 弹窗会列出当前房间候选、全局最佳和每个勾选房间的最佳候选。
- 你可以选择当前房间，即使它时间较短；也可以选择其他勾选房间的最佳座位。

## 优先座位

优先座位用于表达“我更想坐这些座位”。

| 策略 | 说明 |
| --- | --- |
| 最长时段优先 | 先选可用时间最长的座位。 |
| 优先座位优先 | 优先考虑填写的座位；不可用时回退到最长时段。 |

## 首次帮助和主题切换

- 首次打开程序会自动弹出帮助窗口。
- 标题栏 `?` 按钮可以随时重新打开帮助。
- 月亮/太阳按钮可以切换亮色/暗色主题。
- 主题切换需要重启应用才能完全生效。
- 标题栏 `动/低` 按钮可以切换低动画模式。开启后动态渐变会暂停在当前画面，视觉效果基本保留，但窗口打开时的 CPU 占用会降低。

## 关闭和恢复

单账号逐段运行时，如果关闭程序：

1. 程序会先保存当前运行状态。
2. 弹窗询问是否确认退出。
3. 下次打开软件时，会先弹窗展示关闭前的续约计划。
4. 选择“继续计划”后，程序会登录并查询“我的预约”。
5. 若查到有效预约，会询问继续上次计划、重新扫描或停止。

选择“不管”只会清理本地恢复提示，不会取消服务器上的已有预约。测试模式的续约预览不会保存为可恢复任务。
